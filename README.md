# Desafio 01: Landing Page com HTML e CSS

Este projeto faz parte do Bootcamp Frontend da DIO e tem como objetivo criar uma Landing Page responsiva utilizando HTML e CSS, colocando em prática os principais conceitos de estilização.

## Objetivo

- Praticar os fundamentos do CSS
- Utilizar propriedades básicas de estilização
- Trabalhar com unidades de medida relativas e absolutas
- Reproduzir um layout proposto no Figma

## Como usar

1. Faça um fork ou clone deste repositório:
   ```
   git clone https://github.com/seu-usuario/seu-repositorio.git
   ```
2. Abra o projeto em seu editor de código.
3. Edite os arquivos HTML e CSS conforme necessário.
4. Para visualizar, basta abrir o arquivo `index.html` no seu navegador.
